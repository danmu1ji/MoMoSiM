# Media contributors

This page credits artists whose original artwork is included in DanmuTalk or its example worlds. Each contributor's images are grouped together, followed by their chosen credit name and profile link.

No community-contributed artwork is currently included. Entries will be added after the artwork and permission have been reviewed.

Artwork submitted for inclusion must have an explicit permission record. The project code is MIT-licensed; that does not automatically apply to contributed artwork. Unless a submission's recorded terms say otherwise, new volunteer artwork is accepted under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/), with the artist credited here. Existing works retain their own license or permission terms.
