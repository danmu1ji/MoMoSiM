# Volunteer artwork submission form

Live form: [DanmuTalk volunteer artwork submission](https://forms.gle/UnhotZ14Xp66HR4F7). This page records the intended fields and review checklist; keep it aligned with the live form when questions change.

## Form title

DanmuTalk volunteer character artwork submission

## Form description

Submit original artwork for a character profile portrait. Submitting does not automatically grant DanmuTalk permission to use the work; the contributor must explicitly choose a license/permission below. Do not upload official game art, traced/edited official assets, AI-generated work unless explicitly allowed by the project maintainer, or work you do not own or have permission to submit.

## Questions

1. **Character name (Korean name only)** — Short answer, required. Enter only the character’s commonly used Korean name, without family/given name expansion, romanization, or honorifics. Example: `유우카` is accepted. `Hayase Yuuka`, `Yuuka`, and `하야세 유우카` are not accepted. The field is free text, not a dropdown.
2. **Artwork file** — File upload, required. Square 1:1 portrait crop, each dimension at least 1001 pixels, showing the character’s face and shoulders. PNG or JPEG. Google Forms file upload requires contributors to sign in to Google; if that is a barrier, replace this question with a required URL field and accept a link to a file the project can access.
3. **Credit name** — Short answer, required. The name or handle that should appear with the work.
4. **Credit/profile link** — Short answer, required. X, Pixiv, portfolio, or another public attribution page. Accept a direct artwork link when there is no profile page.
5. **Original work and permission** — Required checkbox. “I created this work or am authorized to submit it, and I license it under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). DanmuTalk may display, reproduce, and redistribute it in the application and world-package examples, including commercially, provided attribution and a link to the license are retained. I understand my credit will be shown on the [media contributors page](media-contributors.md).”
6. **Contact (optional)** — Short answer. Email or social handle for follow-up. Do not collect more personal information than needed.

## Review before using submissions

Check the image dimensions and square crop, confirm the Korean character name, verify the credit link, and retain the contributor’s permission record with the asset. Do not include submissions in a release until permission and attribution are recorded.
