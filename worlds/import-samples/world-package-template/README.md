# World package structure template

Minimal fictional scaffold. YAML files retain the package field layout, nesting, and value types, with synthetic sample records. The sample portrait is a generated placeholder SVG.

The scaffold contains one category, character, event, timeline point, state, English locale record, and image. It contains no sound files or voice-reference schema. Replace sample IDs, references, Markdown, and placeholder artwork only with material you made or have permission to use.
