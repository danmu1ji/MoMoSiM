# World package structure template

Minimal fictional scaffold containing no Blue Archive text, names, artwork, recordings, or other game-derived material. YAML files retain the source package field layout, nesting, and value types, with synthetic placeholder records and values.

Includes one category, character, event, timeline point, state, each supported media kind, one English locale record, and one eight-second silent TTS reference. Image slots share a generated placeholder SVG; audio files are silence.

Keep IDs and paths aligned across `index/entities.yaml`, `assets/media.yaml`, and `assets/media-index.json`. Replace all placeholders only with content you created or are authorized to use.
