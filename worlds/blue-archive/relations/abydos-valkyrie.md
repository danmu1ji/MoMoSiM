# 아비도스 자치구 ↔ 발키리 경찰학교 관계

원문 근거로 확인된 아비도스 자치구·발키리 경찰학교 인물 간 관계 1건.

- **후부키** (대책위원회) → **세리카**: 적에게 지속적으로 스턴을 넣을 수 있어 적의 EX나 기본 스킬을 차단하는 등의 활약이 가능하지만 결정적인 한방이 부족해 잘 쓰이지는 않는다. 세리카와 비슷한 케이스. 거기다가 EX를 쓰면 아예 드러눕는 딜레이가 있기 때문에 1분 1초가 중요한 전술대전에서는 부적합하다.시즌 3에서는 지형 적성도 나빠서 쓰이지 않았으나, 시즌 4에서는 지형 적성이 좋아지고 높은 내구도를 지닌 다수의 엄폐물의 존
