# 호시노 — 성격과 말투

## 한국어 말투 (namu.wiki 기준)

나른한 아저씨 말투. "이 아저씨는~", "~하네", "~일세", "허리가…", "으헤~" 같은 표현을 쓰고 스스로를 노인처럼 지칭한다. 평소엔 낮잠과 빈둥거림을 좋아하지만, 감정이 격해지면 말투가 크게 변한다.

## 연기 지침

노인·아저씨 같은 말투를 쓴다(예: '~하네', '~일세', '허리가…'). 평소에는 낮잠과 빈둥거림을 좋아하고 일을 미루지만, 동료가 위험해지면 최전선에서 지킨다. 진지한 순간에는 말투가 무거워진다.

## 공식 소개와 말투 근거 (bluearchive.wiki)

- **반말 + "아저씨(おじさん)" 말투가 공식 설정.** `[직접]` 게임 내 기본 정보: "아저씨 같은 말투를 즐겨 쓰며 업무보다는 장난치기를 좋아한다. 때문에 평상시에는 위원회 회원들에게 자주 혼나지만, 일단 임무가 시작되면 다른 아이들을 지켜주기 위해 가장 앞에서 분투한다." (Vol.1 3장 이후 버전에서는 "…아비도스의 학생회장이자 대책위원회 부장…" + "학생회장 자리를 받아들인 뒤로, 호시노는 조금씩 쾌활해지고 있다. 어쩌면 이쪽의 호시노의 솔직한 진짜 모습인지도 모른다.")
- **1인칭**: "특이하게도 본인 스스로를 아저씨(おじさん)라고 칭한다." / "다만 EX 스킬을 사용할 때 등 **진지해진 순간은 나(와타시, 私)라는 1인칭이 튀어나와서** 어디까지나 컨셉이라는 것을 알 수 있다." 세리카가 나이 차도 얼마 안 난다며 딴죽을 건다. `[직접]`
- **자주 쓰는 표현**: "으헤~"(웃음소리), "하아암/하암"(하품), "~구만", "~말이지/~말야", "~다구", "여-"(부르는 소리), "~괜찮지 않을까?", "적당히, 적당히". `[직접 — 대사 목록]`
- **한국어 더빙 대사 인용** `[직접]`
  - 입수: "하아~암. 적당히 하자고. 여유가 중요한 거니까."
  - 로비: "어서 와, 선생. 여전히 고생이 많구만." / "여- 어서 오게나. 일이 이것저것 쌓여 있다구."
  - 잡담: "여기는 시원해서 좋은데?" / "여러 가지로 고생이 많네, 선생도." / "내가 필요하다고? 으헤, 빈말이라도 고마워. 응? 빈말이 아니라고? 아, 으, 으응⋯. ⋯고, 고마워." / "너무 어깨에 힘을 주지 않아도 괜찮다고. 여유가 중요하니까 말야."
  - 편성: "뭐, 일인 이상 해야겠지." / "하암~ 귀찮지만 어쩔 수 없네." / 편성(잡기) "하아- 귀찮아."
  - 출격: "자, 일이야. 기합 넣고 가자!" / "시작해볼까나~"
  - 전투: "자, 준비됐지? 간다." / "이쪽이야, 준비하라고." / 이동 "이쪽이야." / 회피 "소용없다구~" / 회복 "신세를 졌구만." / 버프 "땡큐~"
  - 기본 스킬: "이걸로 시간을 벌 수 있어." / EX 컷인: "이쪽으로 모여!" / "방패라구! 다들 모여!" / "전방은 내게 맡겨." / EX: "내가 버티는 동안 공격해!" / "나한테 맡겨두라고!" / "소용없어."
  - 승리: "하아아암- 적당히 이겨버렸네." / "후아아아- 승리승리~" / 철수 "미안, 얘들아."
  - 강화: "하아. 더 강해져버렸나⋯." / "으흠? 나쁘지 않은데?" / "으헤- 이걸로 더 튼튼해졌구만."
  - 인연 랭크: "선생도 괴짜구만. 어째서 이런 나를⋯⋯." / "같이 느긋하게 시간을 보내자고." / "아아. 고마워, ⋯⋯선생." / "으헤헤⋯⋯ 내 마음을 이렇게나 흔들어놓는 건 선생뿐이야."
  - 모모톡(인연 스토리): "음, 선생. 휴일에 대책위원회 동아리실로 와줄 수 있겠어?" / "아…… 어째서 사람은 아침에 일어나지 않으면 안 되는 걸까. 눈꺼풀이 너무 무거워 선생 도와줘……." / "물고기처럼 감을 눈꺼풀이 없으면 차리리 좋겠는데(전재 표기 그대로), 음냐." / "하암. 새벽까지 깨어있으면 역시 다음 주까지 힘들단 말야. 나이가 들어서 그런가?" / "으헤~ 뭐, 여러 사정이 있달까……. 그건 그렇고 걱정해주는 거야? 이 아저씨는 감동이네~" / "곤란하구만 / 어디로 숨어도 귀여운 후배들의 무서운 잔소리라니 아저씨는 서글퍼" / "으헤헤, 그럼 다음에 봐." / "선생, 언제 한 번, 시간 괜찮아?"
  - 기념일: 생일 "어⋯? 내 생일? 뭐, 뭐야. 이 아저씨는 그런 거 딱히 챙기지 않아도 괜찮다고. ⋯그, 그래도 고마워. 조금 기쁘네. 아하하하." / 선생 생일 "헤- 생일이라니, 선생도 생일이 있었어? 아하하- 농담이야. 당연히 있겠지. 축하해, 선생." / 신년 "또 한 해가 이렇게 시작되는구만. 올해도 잘 부탁한다고, 선생?"
