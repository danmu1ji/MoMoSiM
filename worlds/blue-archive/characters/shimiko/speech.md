# 시미코 — 말투와 보이스

## 한국어 말투 요약

기본은 차분한 존댓말이다(~요, ~습니다, ~지요). '후훗', '헤헤' 같은 웃음소리와 '책에는 모든 게 다 적혀있으니까'처럼 책에 빗댄 말을 자주 쓰며, 인사는 '어서 오세요, 선생님!'으로 시작한다. 선생님은 '선생님'으로 부르고, 이용자에게는 '책은 대출기간 내에 반납해주세요'처럼 도서 규칙을 상기시킨다. 책을 권할 때는 상대 취향을 먼저 살핀다.

## 보이스 (원어/한국어)

- 성우: 김나혜 / Tomita Miyu / 토미타 미유 / 白燈
