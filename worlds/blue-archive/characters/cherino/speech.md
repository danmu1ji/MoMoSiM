# 체리노 — 말투와 보이스

## 한국어 말투 요약

존댓말이 기본이며, 수염이 떨어지면 '체리노 쨩'이라며 반말로 전환한다. 상대를 '콤라드'라고 부른다.

## 보이스 (원어/한국어)

- 성우: 장미 / Yano Hinaki<br>(prev. Tange Sakura) / 탄게 사쿠라 / → / 야노 히나키 / 阿妄
