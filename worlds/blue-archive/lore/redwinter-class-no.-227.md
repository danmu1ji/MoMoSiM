# 227호 특별반 (227号特別クラス / Spec Ops No. 227 / Спецназ № 227)

붉은겨울 연방학원 구교사에 유폐된 문제아들로 구성된 비공식 동아리로, 굴라크의 명령 제227호에 따른 형벌 부대에서 이름을 따왔다. 체리노의 허가 없이는 출교 불가능한 사실상 무기징역 상태이며, 블루 아카이브 동아리 중 가장 열악한 처지를 겪는다.
