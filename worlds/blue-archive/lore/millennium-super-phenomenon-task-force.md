# 초현상특무부 (特異現象捜査部 (Super Phenomenon Task Force, SPTF / 초현상특무부))

밀레니엄 사이언스 스쿨의 세미나 산하 특무조직으로, 과학적으로 증명이 어려운 초자연 현상의 추적·연구를 목적으로 학생회장 리오가 설립한 동아리다.
