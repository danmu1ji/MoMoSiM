> I was talking with Yuzu in the Game Development Department...
> What started off as a conversation about an old gaming article led to us organizing the bookshelf...and that led to us tidying up the whole club room.
> Game Development Department Club Room
- Yuzu (Game Development Department): Ugh, I just wanted to look up an old gaming review...
- Yuzu (Game Development Department): And then I got so wrapped up in organizing these boxes that I let this turn into a ponderous cleaning session... I'm sorry for dragging you into such tedium, Sensei.
- "It's fine. It's not like I was busy."
- "Wow. There are so many game cartridges..."
- Yuzu (Game Development Department): Well, this is the Game Development Department's room, after all.
- Yuzu (Game Development Department): We collect all sorts of games for inspiration. Constant research is a key part of being a game developer.
- Yuzu (Game Development Department): Although...most of these are a little "retro." They only run on vintage consoles.
- "Huh, what's this...?"
- Yuzu (Game Development Department): What did you find, Sensei?
- Yuzu (Game Development Department): M-Maybe... I don't really remember...
- Yuzu (Game Development Department): Is there anything on the jewel case?
- "It says...'Yuzu' at the bottom."
- Yuzu (Game Development Department): Wh-Wh-Wh-What?! M-My name...?! Me?!
- Yuzu (Game Development Department): H-How... I don't remember making anything like that...
- Yuzu (Game Development Department): Wait... Could it be...
- Yuzu (Game Development Department): W-Wait! Sensei!
- Yuzu (Game Development Department): Th-That CD... Please...let me examine it.
- "Is there a problem?"
- Yuzu (Game Development Department): W-Well... It's more so...
- Yuzu (Game Development Department): ...it might contain some sensitive and private materials.
- Yuzu (Game Development Department): Ugh... Why would something like THIS show up while Sensei's here...?
- Yuzu (Game Development Department): I-I'm really sorry... But could you maybe go into the hallway while I load this?
- "Can't I just turn my back?"
- Yuzu (Game Development Department): N-No! And plug your ears, please!
> Yuzu herded me out of the Game Development Department club room.
> About ten minutes passed...
- Yuzu (Game Development Department): Um, Sensei...
- Yuzu (Game Development Department): Y-You can come in now...
- Yuzu (Game Development Department): I-I'm sorry for earlier. I panicked...
- Yuzu (Game Development Department): Yes. It wasn't anything special.
- Yuzu (Game Development Department): Well... It might not be "special," but it was "important."
- "What do you mean by that?"
- Yuzu (Game Development Department): It was...the gold master disc of the Tales Saga Chronicle Prototype. It's the first game I ever made.
- Yuzu (Game Development Department): Oh, you don't know what "gold master" means...
- Yuzu (Game Development Department): Ah, I'm sorry. I forgot to explain it.
- Yuzu (Game Development Department): Software devs typically call the master disc with the final product in it the "gold master."
- Yuzu (Game Development Department): The term comes from the recording industry—music producers would foil their records in gold for the sake of durability...and pride.
- Yuzu (Game Development Department): Now, it's just an expression. All this is to say that this disc has the final version of my first game.
- Yuzu (Game Development Department): Clearly, it's not gold. No one does that anymore...I think.
- Yuzu (Game Development Department): This CD holds the Tales Saga Chronicle prototype...all before we put it online.
- Yuzu (Game Development Department): I was anxious about it, so scared, that I shoved this CD in a box so I wouldn't have to think about what it started.
- Yuzu (Game Development Department): I can't believe I forgot that I did that.
- "Are you okay now?"
- Yuzu (Game Development Department): Yes, I'm fine.
- Yuzu (Game Development Department): Fine enough, I suppose. I've never fully moved past...all the reviews and criticism this game brought me.
- Yuzu (Game Development Department): Still, now I have so many good memories that they more than make up for that bad period.
- Yuzu (Game Development Department): In retrospect, our club only came together because I released this prototype.
- Yuzu (Game Development Department): If I'd never tried...if I never finished this game, I wouldn't have the bright and wonderful today I have now.
- Yuzu (Game Development Department): Which is why...I...think I can do it. I can face it. It's all right.
- Yuzu (Game Development Department): ...Yes. It's a golden...memory, isn't it? My one and only.
- Yuzu (Game Development Department): Now that I think about it, you've never played the Tales Saga Chronicle prototype, have you?
- Yuzu (Game Development Department): Perhaps...you'd like to give it a try?
- "Yeah! I'd love to!"
- Yuzu (Game Development Department): This PC may have advanced internet, but it still has a CD drive... Let's put it in.
- Yuzu (Game Development Department): H-Haha... It might not be the most optimized. Loading could take a while.
- Yuzu (Game Development Department): E-Error?! H-How...
- Millennium Security System: "Warning. Corrupted code detected. System Critical: CPU Overload Imminent."
- Millennium Security System: "Analyzing code... Concluding that this is unrefined malware of unknown purpose."
- Millennium Security System: "For the security of the PC, the code will be ELIMINATED!"
- Yuzu (Game Development Department): P-Please don't delete my memories!
> Thanks to some quick interference, Yuzu saved her CD from a tragic deletion.
> ...But I had to push back my Tales Saga Chronicle Prototype playthrough to a much later date.
