> Schale Executive Office
> It was a normal afternoon...
> Otogi had come over for her Student Rep shift, and we were going over the SRT Mission Log together.
> "Switch to radio channel 3."
> "This is FOX 4. Are comms clear?"
> "Mission number is M-X-9-2... Not S, X for x-ray."
> Confirmed. Code for ceasing operation is November, Kilo...
- "Is the report going well?"
- Otogi (FOX Squad): Not really. The signal was really bad on this mission, so it's hard to hear what's being said.
- Otogi (FOX Squad): We did install a jamming device before the operation, but the interference is still pretty extreme.
- Otogi (FOX Squad): I need to speak more loudly, even if only to make writing reports easier.
- Otogi (FOX Squad): It sounds more complicated than it actually is.
- Otogi (FOX Squad): First, we're reconfirming the target location and the mission code. That's standard procedure, so really anyone could figure it out.
- Otogi (FOX Squad): Ah, the phonetic code might make things a little difficult if you haven't studied it.
- "'Phonetic code'?"
- Otogi (FOX Squad): Yes. Like Alpha, Charlie, Mike.
- Otogi (FOX Squad): There's a lot of words we use every day that sound similar, right? Like the number two, or the preposition "to."
- Otogi (FOX Squad): Imagine if someone messed up just one letter or number because of that. We could end up bombing the wrong place.
- Otogi (FOX Squad): So we spell using words, so there can't be any mistakes like that.
- Otogi (FOX Squad): For example, FOX from FOX Squad would be Foxtrot-Oscar-X-ray.
- "That's interesting."
- Otogi (FOX Squad): We only use it when there's something we can't afford to confuse, like Tango down, or point Alpha. It'd take way too long if we use phonetic code for everything.
- Otogi (FOX Squad): Do you want to try, Sensei?
- "I wouldn't be able to keep up."
- Otogi (FOX Squad): Here, just follow the alphabet. And there's no stakes anyway. It's not like it's a real mission.
- Otogi (FOX Squad): This is FOX 4. Headquarters, respond.
- "Th-This is Schale... I mean Sierra 1. Message received."
- Otogi (FOX Squad): FOX 4. Confirmed.
- Otogi (FOX Squad): Sierra 1. What are the contents of the afternoon snack delivery?
- Otogi (FOX Squad): What? I can't hear you!
- Otogi (FOX Squad): Crackle, crackle! Too much interference! Did you say cake or shake?
- "Relaying once more, FOX 4."
- "Today's snack is Charlie-Alpha-Kilo-Echo. Over."
- Otogi (FOX Squad): Fufu. Then cake it is.
- Otogi (FOX Squad): Sierra 1, please check what flavors there are.
- "Do you prefer Charlie or Sierra?"
- Otogi (FOX Squad): Chocolate or strawberry... Sierra, of course!
- Otogi (FOX Squad): Yeah. Some of the terms are a little obscure, but it's no different from military jargon.
- Otogi (FOX Squad): You might find that using phonetic code comes more naturally with some practice.
- "I actually think I shouldn't use it."
- Otogi (FOX Squad): Huh? Why not? It's good for security and communication.
- "But I'm a teacher."
- Otogi (FOX Squad): Wow, what you said is Sierra Hotel.
- Otogi (FOX Squad): Ah, w-well...
- Otogi (FOX Squad): I mean it's fitting as Schale's S-Sensei!
- Otogi (FOX Squad): Oh, come to think of it... We used too much time chatting.
- Otogi (FOX Squad): I'll go back to my seat to write the report.
> Otogi awkwardly changed the topic to the report, clearly embarrassed by something.
