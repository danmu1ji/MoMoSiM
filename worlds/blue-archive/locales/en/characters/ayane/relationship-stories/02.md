> I arrived at Abydos School and saw a truck piled with scrap metal getting ready to leave.
- Scrap Metal Dealer: Thank you as always, Ayane.
- Ayane (Foreclosure Task Force): Heehee. No, thank you.
- Scrap Metal Dealer: I think this is a good price and your timing couldn't be better. I'll send it to the recycling center and have it put in the furnace.
- Scrap Metal Dealer: Take care!
- Ayane (Foreclosure Task Force): You too! Thank you!
- Ayane (Foreclosure Task Force): Oh, Sensei!
- "Who was that?"
- Ayane (Foreclosure Task Force): That was a scrap metal dealer that we've been working with for a long time. We just worked out a pretty good deal!
- Ayane (Foreclosure Task Force): But you didn't have to come all the way out here...
- "Where did you find all that scrap metal?"
- Ayane (Foreclosure Task Force): It was inside the abandoned storage facility in the far corner of the school. It was covered by a tarp, so for the longest time I didn't even know it was there.
- Ayane (Foreclosure Task Force): It weighed 300 kilograms, so I got a pretty good price for it.
- "Which storage facility are you talking about?"
- Ayane (Foreclosure Task Force): What?
- Ayane (Foreclosure Task Force): ...Is there something wrong?
- Ayane (Foreclosure Task Force): It's this way.
> *clank*
- Ayane (Foreclosure Task Force): This is the place. It's a little messy since they seem to keep all the waste materials here as well...
- Ayane (Foreclosure Task Force): I found it under this tarp here.
- "Let's check under the tarp."
- Ayane (Foreclosure Task Force): Huh...?
- Ayane (Foreclosure Task Force): Hey, there's something written on it... Handle with caution. This is special high-grade steel that must be kept in a climate-controlled environment.
- Ayane (Foreclosure Task Force): Special high-grade steel?
- Ayane (Foreclosure Task Force): High...grade...?!
- ...
- Ayane (Foreclosure Task Force): ...
- Ayane (Foreclosure Task Force): CRAP!
- Ayane (Foreclosure Task Force): I can't reach the scrap metal dealer!
- Ayane (Foreclosure Task Force): He's not picking up his phone!
- Ayane (Foreclosure Task Force): Wh-What do I do?
- Ayane (Foreclosure Task Force): ...Y-Yeah!
- Ayane (Foreclosure Task Force): ...Y-Yeah!
- Ayane (Foreclosure Task Force): Focus, Ayane... Stay calm and let's figure this out...!
- Ayane (Foreclosure Task Force): Okay, first let's assess the situation.
- Ayane (Foreclosure Task Force): *exhale*
- Ayane (Foreclosure Task Force): *ding*—!
- Ayane (Foreclosure Task Force): The scrap metal truck is probably headed to the freight station to meet the train that goes to the recycling center.
- Ayane (Foreclosure Task Force): After it's loaded onto the freight train, the scrap metal will be impossible to track down!
- Ayane (Foreclosure Task Force): And we won't be able to find it after it gets on the highway to the freight station, either!
> *tap* *tap* *tap* *tap*
- "What if we just call the freight station?"
- Ayane (Foreclosure Task Force): The freight station is unmanned, so there won't be anyone there to call. And even if we leave now, the truck will get there before us.
- Ayane (Foreclosure Task Force): Going to the freight station would be a waste of time!
- "Then what should we do?"
> *tap* *tap* *tap* *tap* *tap*
- Ayane (Foreclosure Task Force): I'm trying to figure out the route the scrap metal dealer will take.
- Ayane (Foreclosure Task Force): Thankfully, he's been working with our school for so long and I have all his information recorded.
> *tap* *tap* *tap* *tap* *tap* *tap*
- Ayane (Foreclosure Task Force): Where will he go next? Hmmm... He usually goes to the construction material management center at the Abydos shopping district.
- "So we should go there?"
- Ayane (Foreclosure Task Force): Well, only if the truck has any room left!
- Ayane (Foreclosure Task Force): That truck is currently loaded with 300 kilograms of cargo! That means it can't possibly take on anything else at the construction material management center!
- Ayane (Foreclosure Task Force): That place only carries large amounts of cargo!
- "So, what do we do then?"
- Ayane (Foreclosure Task Force): Well, if he just passes it by, the next place he'll probably go is...
- Ayane (Foreclosure Task Force): ...
- Ayane (Foreclosure Task Force): ...This is it! Abydos Central Park District 3!
- Ayane (Foreclosure Task Force): That park is being demolished, so he'll probably want to load his truck with smaller items!
- Ayane (Foreclosure Task Force): It's only three kilometers away! That's so close!
- Ayane (Foreclosure Task Force): He should be there in about...ten minutes!
- "Should we take a taxi? Or do you know someone with a car?"
- Ayane (Foreclosure Task Force): No, a taxi won't get us there in time...
- Ayane (Foreclosure Task Force): ...I think we'll have to run.
- "What do you mean 'run'?!"
- Ayane (Foreclosure Task Force): The truck will be taking a non-linear path and dealing with traffic signals. Based on my calculations, we can run three kilometers and get there under ten minutes!
- "What?"
- Ayane (Foreclosure Task Force): Sensei, I'm going to need you to be my navigator.
- "...What?!"
- Ayane (Foreclosure Task Force): I can't run and read the directions at the same time... You'll have to tell me where to go!
- Ayane (Foreclosure Task Force): Let's go!
> Ayane disappeared like the wind.

- Ayane (Foreclosure Task Force): Uh, it's nothing! Just tell me what to do next!
- Ayane (Foreclosure Task Force): *pant* *pant* *pant*
- Ayane (Foreclosure Task Force): I should... *pant* ...really start... *pant* *pant* ...working out...
- Ayane (Foreclosure Task Force): Okay, I made it... *pant* *pant* ...Wait, sir!

- Ayane (Foreclosure Task Force): W-Wait... *pant* ...just a minute... The cargo...
- Ayane (Foreclosure Task Force): Car...go...

> Eventually, we got twice the original amount for the high-grade scrap metal.
